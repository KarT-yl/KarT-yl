## Featured project

### [Practical Automations](https://github.com/KarT-yl/practical-automations)

A growing collection of small tools for everyday workflows. The first project is **Amex Offers — One Click + Reports**, an Opera GX extension that adds available offers and turns saved offers into a local report.

- One-click enrollment with progress and a Stop button.
- Expiry and reward analysis, with cash and points kept separate.
- CSV, HTML, and printable reports.
- Plain JavaScript, Manifest V3, browser integration tests, and documented limitations.

Start with a concrete problem, build something useful, document how to run it, and test the behavior that can go wrong. Keep assumptions and limitations visible.
